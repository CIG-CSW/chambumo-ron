### Chambumo-Ron Insights: Interactive Research Query Tool

#### Overview
The Chambumo-Ron Insights Dashboard is an interactive interface for exploring historical, providential, and cultural texts concerning the epic history of the Han People, the providence of Heaven, and the teachings of True Parents. Built with a modern UI and connected to an AI-powered Google Apps Script backend, it allows users to ask natural language questions and receive synthesized answers based on the core research documents.

#### Data Context & Themes
The data accessed by the AI is curated from historical and religious research documents. The primary themes categorized in the tool include:
*   **Providence & History:** Details the Heavenly Parent's 6,000-year history of the providence of salvation and the 4,000-year preparation of the chosen people.
*   **True Parents:** Explores the theological concept of the Only Begotten Son and Only Begotten Daughter, and their union as the True Parents of humankind.
*   **Korean Heritage:** Examines the ancient origins of the Han people of Korea, their founding legend of Dangun, the philosophical ideal of *hong-ik in-gan* (devotion to the welfare of all humankind), and traditional practices such as offering rituals to Heaven.
*   **Christianity:** Analyzes the 2,000-year history of Christianity as a preparation for the advent of the Only Begotten Daughter.

#### Features
*   **AI-Powered Querying:** Ask questions in natural language and receive synthesized answers based strictly on the provided research context.
*   **Responsive Glassmorphism UI:** A modern, dark-mode aesthetic utilizing deep slate backgrounds, semi-transparent blurred cards, and subtle hover animations for premium readability.
*   **Serverless Architecture:** The frontend is a static HTML/Tailwind CSS file hosted on GitHub Pages, securely bridged to the Gemini AI via a hidden Google Apps Script backend.

#### Technical Stack
*   **Frontend:** HTML5, Tailwind CSS (via CDN), Vanilla JavaScript (ES6)
*   **Backend:** Google Apps Script (Serverless Web App)
*   **AI Model:** Google Gemini API
